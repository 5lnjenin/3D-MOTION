# 3D MOTION — الإصدار 24، نسخة اختبار لإضافة الفيديو

[تحميل المشروع الكامل: 24.zip](24.zip) · [تقرير هذا التعديل](CHANGES_VIDEO_IMPORT_AR.md)

بعد بلاغ الإغلاق عند اختيار الفيديو، أصبح نسخ الملف في الخلفية، مع فحص
فك صورة وجاهزية التشغيل قبل ربطه بالمشهد. تظهر أخطاء الإضافة في تنبيه
بزر نسخ التفاصيل. يُحفظ آخر إجراء، ويظهر عند العودة إلى المحرر إذا انقطعت
الإضافة، حتى عندما يكون كونسول Playgrounds فارغًا.

سبب الإغلاق على جهاز المستخدم لم يُثبت بعد. هذه نسخة اختبار؛ تحقق Apple
للمصادر الحالية لم يكتمل. لا تنسب نتائج النسخة السابقة إلى هذه النسخة.

مشروع Swift Playgrounds كامل داخل `3DMOTION24.swiftpm`، لـiPadOS 17 أو أحدث.
فك الضغط في مجلد جديد وافتح المشروع الجديد؛ رقم التطبيق الظاهر يبقى 24.
النسخ يحافظ على بايتات الفيديو الأصلي والدقة وموارد المشروع. استخدام
`SHA256SUMS` يتحقق من سلامة التنزيل.

## نتائج هذا التعديل

- نجح بناء كود النسخ والسجل و8 اختبارات على Linux / Swift 6.0.3، صفر إخفاقات.
- نجح نسخ البايتات والإلغاء أثناء النسخ وإزالة الجزء الناقص وحماية الملفات الموجودة.
- نجحت استعادة سجل المرحلة بعد نسخة جديدة ومنع خلط الإلغاء والفشل مع الانقطاع.
- نجح فحص صياغة 43 ملف Swift في الجذر وملفي XCTest؛ هذا ليس بناء iOS.
- أصبحت المجموعة المسجلة 67 حالة Apple، مع نافذة عرض فعلية وفيديوين وتشغيل تلقائي.
- تحقق Apple وبناء IPA الحاليان: IMPORT_BUILD_LINKS_PENDING
- تشغيل Swift Playgrounds على iPad وملف الفيديو الخاص بالمستخدم لم يُختبرا هنا.

## إذا تكرر الإغلاق

أعد تشغيل Playgrounds وافتح المحرر. يظهر آخر إجراء مسجل إذا لم تكتمل الإضافة؛
اختر «نسخ التفاصيل» للمشاركة يدويًا. هذا السجل يساعد التشخيص ولا يحدد سبب
إنهاء النظام وحده. عند غياب رسالة، يحتاج التحقيق الفيديو نفسه أو سجل إنهاء
النظام. التطبيق لا يرسل بيانات التشخيص تلقائيًا.
