# 3D MOTION — الإصدار 24

مشروع Swift Playgrounds كامل لمحاولة معالجة فقدان خامات SceneKit عند حفظ المشاريع واستعادتها.

## التحميل والتجربة

نزّل [24.zip](24.zip)، ثم فك الضغط وافتح `3DMOTION24.swiftpm` باستخدام Swift Playgrounds على iPad.

اقرأ [التقرير العربي](REPORT_AR.md) لمعرفة السبب الجذري المثبت في الكود والتغييرات وحدود التحقق.

نجح تشغيل 14 اختبارًا آليًا لصيغة ملف المشروع والحفظ الآمن في بيئة Linux. تعذّر تشغيل بناء iOS واختبارات SceneKit في هذه البيئة؛ تتضمن الحزمة 13 اختبار Apple وتعليمات التحقق على الآيباد. لم يتم إثبات سلوك SceneKit أو تجميع iOS عمليًا بعد.

ملف ZIP هو النسخة الجاهزة نفسها؛ يمكن التحقق من سلامته باستخدام `SHA256SUMS`.
