# 3D MOTION 24 — ورشة الأدوات

النسخة الحالية على `fix/video-import-crash` تضيف ورشة نمذجة وBoolean وUV وتشويه،
24 خامة محلية، ستة ملفات خطوط، ستة أنماط إضاءة، وجلد glTF واختيار المقاطع
والحساب المكعب وIK المحفوظ وتراجع روابط الفيزياء. بقيت ميزات الفيديو والصوت
والمشاريع والاستيراد والتصدير والأيقونة ومعرّف التطبيق.

مصدر البناء المختبر: `ce10a7d411228d2c909e70d3b675e2ba3893f87f`.

وبناء arm64 Release المحسّن نجحا. التعبئة النهائية تضيف الوثائق والأدلة
وتتحقق من تطابق بايتات مدخلات المصدر والموارد الـ140 مع البناء المختبر.

إنشائهما داخل Tests. الملفات والخطوط وتراخيصها والاختبارات ضمن الأرشيف.

الوظائف المحددة في التقرير منفذة ومختبرة. لم تُنفذ مكتبة Blender المكتبية
كاملة أو Sculpt باللمس أو UV seams/unwrap أو Bevel عام أو Geometry Nodes
ومحاكاة السوائل. أدوات الهندسة لها حدود معلنة وتمنع فقدان الجلد والمورف
وUV الإضافي. بعض glTF sparse/الضغط ما زال غير مدعوم. أداء iPad الفعلي
والتوقيع والتثبيت والترقية وبلاغ ملف Playgrounds المحدد تحتاج تحققًا على الجهاز؛
لا تعادل اختبارات المحاكي اعتماد هذه الفحوص.
